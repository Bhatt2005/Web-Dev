# My First Webpage

A simple 3-page personal website built with HTML and CSS.

## Pages

- **index.html** — Homepage with a short intro, hobbies list, and favourite foods
- **about.html** — About page with personal details
- **feedback.html** — Feedback form with validation

## Features

- Dark theme
- Responsive navigation
- Feedback form with:
  - Text and email inputs
  - Radio buttons for rating and interests
  - Country dropdown
  - Message textarea
  - HTML5 form validation

## How to Run

Just open `index.html` in your browser. No setup needed.

## Built With

- HTML5
- CSS3
