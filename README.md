# Website Updates – Spring Assignment

## Overview

This update enhances the website by introducing responsive design principles, Bootstrap components, and a dedicated photo gallery page. The website is now fully responsive and provides a consistent user experience across desktop, tablet, and mobile devices.

## New Features Added

### 1. Bootstrap Navigation Bar

* Added Bootstrap CDN to all website pages.
* Implemented a responsive Bootstrap navbar.
* Added a mobile-friendly hamburger menu for smaller screens.
* Ensured consistent navigation across all pages.
* Navigation links include:

  * Home
  * About
  * Feedback
  * Photos

### 2. New Photos Page

A new page, `photos.html`, has been created to showcase images using modern CSS layout techniques.

#### Flexbox Gallery

* Created a photo gallery using CSS Flexbox.
* Displays images in a flexible and responsive layout.
* Automatically adjusts the number of images per row based on screen size.

#### Grid Gallery

* Created a second gallery using CSS Grid.
* Provides a structured and organized image layout.
* Fully responsive across different devices.

### 3. Responsive Design Improvements

The entire website has been optimized for responsiveness.

#### Mobile Devices (≤ 768px)

* 1 image displayed per row.
* Navigation collapses into a hamburger menu.
* Images automatically resize to fit the screen.

#### Tablets (769px – 1024px)

* 2 images displayed per row.
* Improved spacing and layout for medium-sized screens.

#### Desktop Devices (> 1024px)

* 4 images displayed per row.
* Full navigation menu visible.
* Optimized gallery presentation.

### 4. Bootstrap Utility Classes

Implemented Bootstrap utility classes throughout the website, including:

* `container`
* `navbar`
* `navbar-expand-lg`
* `text-center`
* `p-3`
* `m-2`

## Technical Improvements

* Added responsive media queries.
* Eliminated horizontal scrolling issues.
* Improved image scaling and responsiveness.
* Maintained consistent styling across all pages.
* Enhanced overall user experience and accessibility.

## Pages Included

* `index.html`
* `about.html`
* `feedback.html`
* `photos.html`

## Result

The website is now fully responsive, visually consistent, and includes modern image gallery implementations using both Flexbox and CSS Grid while leveraging Bootstrap for navigation and layout management.
