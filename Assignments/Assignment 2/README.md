# Web Development Assignment 1

This project contains JavaScript and HTML solutions for Assignment 1.

## Files

| File | Task |
|------|------|
| `evenOrOdd.js` | Checks whether a number is even or odd |
| `multiplicationTable.js` | Prints the multiplication table of a number up to 10 |
| `fizzBuzz.js` | Prints FizzBuzz output for numbers 1 to 20 |
| `squarePattern.js` | Prints a square pattern of stars |
| `trianglePattern.js` | Prints a right-angled triangle pattern of stars |
| `colorChanger.html` | Webpage that dynamically changes background color of a div |

## How to Run

### JavaScript Files (Tasks 1–5)

Make sure Node.js is installed. Then in the terminal:

```bash
cd "/Users/karan/Desktop/WEB 2"
node evenOrOdd.js
node multiplicationTable.js
node fizzBuzz.js
node squarePattern.js
node trianglePattern.js
```

### HTML File (Task 6)

Open `colorChanger.html` in a browser directly, or use the **Live Server** extension in VS Code:
1. Right-click `colorChanger.html`
2. Select **Open with Live Server**
